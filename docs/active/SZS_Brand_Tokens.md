# SZS Brand Tokens

| Token | Hex | Usage |
| --- | --- | --- |
| Obsidian | `#020500` | Main application background |
| Mana | `#DDFBD0` | Body text and nominal state |
| Plum | `#5F0F40` | Panels, drawers, and cards |
| Radar | `#086375` | Borders, accents, and active traces |
| Plasma | `#FE5F00` | Urgent alerts, unpaid deposits, and missing data |
| Gold | `#E0CA3C` | Financials, vitals, and active selection |

## Typography

- Montserrat Alternates: primary headings and labels
- Grenze Gotisch: display accents
- Jacques Francois: body copy
- Odibee Sans and monospace: command input, telemetry, and captions

The Command HUD theme tokens are defined in
`apps/command-hud/src/index.css`.
